🔌 REST API

Connect to a Broker

POST /api/brokers/connect { "brokerId": "my-exness", "brokerCode": "EXNESS", "username": "your_username", "password": "your_password", "accountNumber": "123456789", "accountType": "real" }

Get Account Status

GET /api/brokers/{brokerId}/status Response: { "success": true, "status": { "isConnected": true, "accountBalance": 5000.50, "freeMargin": 2650.75, "marginLevel": 206.03 } }

Submit Real Withdrawal

POST /api/brokers/{brokerId}/withdraw { "amount": 500.00, "currency": "USD", "destinationAccount": "trading@example.com" } Response: { "success": true, "withdrawal": { "withdrawalId": "txn-123456", "amount": 500.00, "status": "pending" } }

Get Withdrawal History

GET /api/brokers/{brokerId}/withdrawals?limit=50 Returns: Complete withdrawal history with status tracking

Global Statistics

GET /api/stats/global Returns: Aggregated statistics across all connected brokers
